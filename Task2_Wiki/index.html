HTML

From Wikipedia, the free encyclopedia

Introduction

HyperText Markup Language (HTML) is the standard markup language used to create and structure content on the web.

HTML describes the structure of a webpage using elements and tags. It can be used to create headings, paragraphs, links, images, tables, forms, lists and many other types of content.

History

HTML was developed by Tim Berners-Lee in the early 1990s while working at CERN. It was designed to allow documents to be linked together using hypertext.

Over time, HTML evolved through several versions. Modern web development primarily uses HTML5 and its associated standards.

Features

HTML provides many features for structuring web content:

  • Headings and paragraphs
  • Hyperlinks
  • Images and multimedia
  • Ordered and unordered lists
  • Tables
  • Forms
  • Semantic elements

Uses
