About the Project

CLI Tool is a command line application developed using Python. The project provides a simple way to interact with different functionalities through a terminal-based interface.

The main purpose of this project is to practice Python programming, object-oriented programming, user input, control flow and command line interaction.

Features

Command Line Interface

Users can interact with the application directly through the terminal.

User Input

The application accepts input from the user and performs operations based on the selected options.

Python Based

The entire application is implemented using Python.

Technologies Used

  • Python
  • Object-Oriented Programming
  • Command Line Interface

How to Use

  1. Clone the repository.
  2. Open the project directory.
  3. Run the Python application from the terminal.
  4. Follow the instructions displayed by the CLI. 
python main.py
